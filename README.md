# TK Tracker 违规记录插件

这是一个用于 AstrBot 的 BF1 群管辅助插件。它会监听白名单管服机器人发送的踢人播报，记录玩家 ID、违规原因和时间，并提供查询、排行和数据管理指令。

## 本次优化

- 使用 Python 内置 SQLite 增量保存记录，不再把全部数据长期放在内存中。
- 新增玩家与记录索引，查询和删除不再遍历整份历史数据。
- 每次新增记录只写入一行，不再重写完整 JSON 文件。
- 自动迁移旧版 `records.json`，迁移完成后保留原文件作为备份。
- 缓存管理员与管服机器人名单，减少每条消息的重复转换。
- 限制异常长的玩家 ID 和原因文本，避免意外占用大量存储。
- 插件停用或卸载时主动关闭数据库连接。
- 精简帮助页和回复文案，减少装饰性表情符号。

SQLite 来自 Python 标准库，不需要安装额外依赖。

## 安装

1. 确保 AstrBot 已安装并运行。
2. 将 `astrbot_plugin_tk_tracker` 文件夹放入 AstrBot 的 `data/plugins/` 目录。
3. 在 AstrBot 控制台重载插件。
4. 在插件配置中填写超级管理员 QQ 号和管服机器人 QQ 号。

## 指令

| 指令 | 功能 | 权限 |
| --- | --- | --- |
| `/tk帮助` | 查看简明帮助 | 所有人 |
| `/tk查 <玩家ID>` | 查看累计次数和最近 5 条记录 | 所有人 |
| `/tk排行` | 查看被踢次数前 10 名 | 所有人 |
| `/tk清空 <玩家ID>` | 删除指定玩家的全部记录 | 管理员 |
| `/tk清空全部` | 删除全部记录 | 管理员 |

## 播报格式

消息发送者必须位于管服机器人白名单中，消息需能匹配以下结构：

```text
踢出玩家 <玩家ID> 成功
原因：<违规原因>
```

关键词之间可以有换行或多个空格。

## 数据存储与旧版迁移

新版本优先使用 AstrBot 官方插件数据目录：

```text
data/plugin_data/astrbot_plugin_tk_tracker/records.db
```

较旧的 AstrBot 版本不支持统一数据目录时，会回退到插件内部的：

```text
data/tk_tracker/records.db
```

首次启动时，插件会查找旧版 `records.json` 并自动导入 SQLite。导入成功后不会重复迁移，旧 JSON 文件不会被删除。
